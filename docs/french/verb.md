# 常用动词

## être

| 人称       | 现在时 | 未完成过去时 | 简单将来时 | 条件式现在时 | 虚拟式现在时 |
| ---------- | ------ | ------------ | ---------- | ------------ | ------------ |
| je         | suis   | étais        | serai      | serais       | sois         |
| tu         | es     | étais        | seras      | serais       | sois         |
| il/elle/on | est    | était        | sera       | serait       | soit         |
| nous       | sommes | étions       | serons     | serions      | soyons       |
| vous       | êtes   | étiez        | serez      | seriez       | soyez        |
| ils/elles  | sont   | étaient      | seront     | seraient     | soient       |

| 形式       | 变位                                                         |
| ---------- | ------------------------------------------------------------ |
| 过去分词   | été                                                          |
| 复合过去时 | j'ai été, tu as été, il a été, nous avons été, vous avez été, ils ont été |
| 命令式     | sois（你）/ soyons（我们）/ soyez（您、你们）                |
| 现在分词   | étant                                                        |

## avoir

| 人称       | 现在时 | 未完成过去时 | 简单将来时 | 条件式现在时 | 虚拟式现在时 |
| ---------- | ------ | ------------ | ---------- | ------------ | ------------ |
| j'         | ai     | avais        | aurai      | aurais       | aie          |
| tu         | as     | avais        | auras      | aurais       | aies         |
| il/elle/on | a      | avait        | aura       | aurait       | ait          |
| nous       | avons  | avions       | aurons     | aurions      | ayons        |
| vous       | avez   | aviez        | aurez      | auriez       | ayez         |
| ils/elles  | ont    | avaient      | auront     | auraient     | aient        |

过去分词：eu；命令式：aie / ayons / ayez；现在分词：ayant。
